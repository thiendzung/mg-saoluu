# MG Sao Luu v1.3.0-rc5

RC5 remediates the remaining RC4 rollback mismatch.

RC4 restored the exact table/view inventory but the stable database hash still differed only in `mg_options`. The cause was plugin operational state that intentionally survived rollback inside the DB: migration replay nonces and audit events.

RC5 moves new replay and audit writes to atomic private JSON files outside webroot:
- `migration-nonces.json`
- `audit-log.json`

Legacy DB options remain readable for compatibility, but new operations do not append to them. This lets rollback restore the checkpoint database exactly while replay protection and audit evidence survive independently of the restored DB.

RC4 schema reconciliation and all migration security/performance gates remain active. Real Production mutation remains hard-blocked.
