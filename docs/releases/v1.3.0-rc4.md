# MG Sao Luu v1.3.0-rc4

RC4 remediates the RC3 runtime rollback-schema blocker.

## Fix
Before Restore/Migration, the journal records the exact database table/view inventory. Rollback imports the checkpoint, removes schema objects that did not exist at baseline, and then requires exact inventory equality before success.

The observed RC3 case is now a regression contract:
- baseline: 12 DB objects;
- after migration: 83;
- reconcile removes 71;
- rollback must end at exact 12.

Missing inventory, failed drops, or residual schema mismatch fail closed.

All RC3 migration security and performance gates remain in scope. Real Production mutation remains hard-blocked.
