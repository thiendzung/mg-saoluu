# MG Sao Lưu v1.2.1-rc5 — Sửa lỗi Rollback

**PRE-RELEASE — chỉ Local/Staging clone. Production restore luôn bị khóa.**

## 4 bước
1. **Backup:** sao lưu database và file WordPress được hỗ trợ thành gói mã hóa.
2. **Verify:** kiểm tra gói sao lưu và Recovery Key.
3. **Restore:** khôi phục trên WordPress clone độc lập có DB/user riêng.
4. **Rollback:** quay về checkpoint trước restore; xác minh dữ liệu và dọn file mới.

## Thay đổi so với RC4
- Sửa lỗi upload checkpoint qua UI có tên file tạm khiến rollback bị từ chối.
- Xác minh đúng journal + SHA-256 checkpoint đang lưu + SHA-256 bản upload. Không cho dùng checkpoint cũ hoặc bị sửa.
- Không thêm chức năng khác; backup format và giới hạn production không đổi.

## Cài thử
- Tải ZIP và đối chiếu SHA256 file đính kèm.
- Trước nâng plugin trên motgu.test: giữ checkpoint DB + wp-content độc lập.
- Backup/Verify trên Local; Restore/Rollback **chỉ ở clone** đã cách ly email, payment, webhook, cron.
- UI đã có **Khôi phục từ bản đang lưu**: dùng khi upload PHP chỉ 2 MB; không tăng PHP limit không cần thiết.
- Kiểm bài viết, sản phẩm, ảnh, Astra header, URL/GUID, `.maintenance`, rollback checkpoint và file cleanup.

## Chưa nghiệm thu
- Runtime restore và rollback trên exact RC5 ZIP chờ Agent Local báo PASS.
- Physical disk-full chưa test.
- Serialized object phức tạp có thể còn URL nguồn sau chuyển tên miền; kiểm lại trên clone.
- Backup không bao gồm wp-config.php, .htaccess hoặc Recovery Key, cần Recovery Kit riêng.

**Mục tiêu:** Backup → Verify → Restore → Rollback chính xác, an toàn, ít thao tác.
