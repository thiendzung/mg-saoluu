# MG Sao Luu v1.3.0-rc3

Pre-release candidate that rebases signed Local -> fresh Production migration onto the runtime-accepted v1.2.1 Backup/Restore base.

## Key points
- Retains RC7-RC9 Backup/Restore hardening from v1.2.1.
- Adds Ed25519 migration grant bound to exact encrypted archive SHA, source and target.
- Requires matching DB prefix and a strictly fresh target including Woo HPOS checks.
- Canonical-host, HTTPS, disabled WP-Cron and external-I/O isolation gates.
- RC3 still hard-blocks mutation on real Production; only isolated Staging QA can exercise writes.
- Backup-tab migration picker uses metadata only; expensive freshness queries run only on Stage/Apply.

Runtime migration acceptance is required before any prerelease publication or merge.
