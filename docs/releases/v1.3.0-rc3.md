# MG Sao Lưu 1.3.0-rc3 — canonical Local → Production URL migration candidate

**Pre-release. Real production Restore/Migration remains hard-blocked in every RC. RC1/RC2 are superseded for QA.**

RC3 contains all RC2 safety gates: canonical WordPress host identity, encrypted Local migration package, target/archive-bound Ed25519 one-time grant, strict empty target, matching DB prefix, public DNS-only target, external-I/O isolation acknowledgement, disabled WP-Cron, independent rollback checkpoint, target MG Sao Luu plugin preservation, and Staging-only mutation QA.

## RC3 URL fix
- Backup manifests use WordPress URLs that commonly include a trailing slash. RC3 converts source and target URLs to canonical bases before database replacement, so both `https://abc.test` and `https://abc.test/path` are migrated.
- If WordPress core has a different `site_url` under a subdirectory, the longer source URL is replaced first; this prevents the shorter home URL replacement from making the core-path mapping impossible.
- `posts.guid` remains excluded by the database replacement engine.
- Complex/unsafe serialized objects may still retain an old URL rather than executing classes or corrupting data; Agent Local must audit remaining source-host strings after restore.
