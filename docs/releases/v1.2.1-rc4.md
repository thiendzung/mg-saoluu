# MG Sao Lưu v1.2.1-rc4 — Bản thử nghiệm đầu tiên tải được

**Trạng thái: PRE-RELEASE — dùng để thử nghiệm, không phải bản triển khai production.**

## Plugin làm gì?
1. **Backup:** sao lưu database + các file WordPress được hỗ trợ, mã hóa bản sao.
2. **Verify:** kiểm tra gói sao lưu, CRC/hash, giải mã bằng Recovery Key.
3. **Restore:** nhập bản sao trên một WordPress Local/Staging clone riêng và thay URL an toàn.
4. **Rollback:** tạo checkpoint trước restore, tự quay lại khi phát hiện lỗi.

## Bản này sửa lỗi
- Khôi phục không bị ngắt vì object Astra `Astra_Builder_Header` trong dữ liệu PHP serialized.
- Không quét đệ quy vô hạn với tham chiếu vòng, object hoặc dữ liệu serialized quá sâu; giữ nguyên bytes không thể xử lý an toàn.
- Chạy kiểm tra mã nguồn, integrity, contract và ZIP đã giải nén trước khi xuất bản.

## Cách dùng (ngắn)
1. Trên site **Local** cần sao lưu, cài plugin qua **Plugins → Add New → Upload Plugin**; kiểm tra nơi lưu backup ngoài webroot và đủ dung lượng.
2. Chọn **Sao lưu → Backup mã hóa**, lưu bản `.mgbackup` và Recovery Key ở **hai nơi riêng**.
3. Chọn **Xác minh** để kiểm tra bản vừa tạo.
4. Muốn thử restore: tạo **Local/Staging clone riêng với DB/user riêng**, tắt email, payment, webhook và cron thật trước khi nhập; tại tab **Khôi phục**, chọn backup và Recovery Key. Xác minh URL, bài viết, media, giao diện, database và rollback.

## Giới hạn đã biết
- **Restore trên Production bị khóa hoàn toàn trong RC4**. Không dùng để đồng bộ hai chiều hay tự triển khai website live.
- Dữ liệu serialized chứa object/enum/tham chiếu vòng có thể giữ URL nguồn; sau restore phải kiểm tra link/cấu hình trong clone. Không gọi việc này là 100% URL migration.
- **Chưa kiểm thử** tình huống đầy ổ đĩa vật lý và dữ liệu custom table đặc thù; không khẳng định các trường hợp này đã PASS.
- Backup không bao gồm `wp-config.php`, `.htaccess`, Recovery Key hoặc credentials; lưu Recovery Kit riêng.
- Đây là prerelease để **sửa lỗi theo vòng lặp nhỏ**; không dùng cho site khách thật khi chưa nghiệm thu riêng.

## Dấu hiệu release đáng tin cậy
- GitHub tag `v1.2.1-rc4` trỏ tới commit đúng phiên bản.
- Bản ZIP cài WordPress chứa thư mục `mg-saoluu/`, 27 file plugin có hash trong `integrity.json`, cộng chính manifest.
- Có kèm SHA256SUM và thông báo kiểm thử. Nếu GitHub Actions chưa PASS, **không phát hành bản ZIP như đã nghiệm thu**.
